# 轻餐 SaaS PC Demo

面向轻餐商户的一期 PC 经营工作台原型。默认首页采用 AI Native 的任务交互方式：经营者提出目标，系统展示取数与分析过程、引用证据，并在执行高风险动作前请求人工批准。传统订单、商品、会员和对账能力作为业务工具与任务上下文存在。

## 启动

```bash
npm install
npm run dev
```

默认访问 `http://127.0.0.1:4173`。

## 构建

```bash
npm run build
```

## 当前范围

- 类 Codex 的经营任务列表和对话执行区
- 订单、支付、外卖等经营数据上下文
- AI 分析步骤、异常证据和经营机会
- 商品上下架等高风险动作的人工审批
- 传统业务系统导航与响应式窄屏布局

当前数据均为前端演示数据，尚未接入后端 API、登录权限和真实支付渠道。
